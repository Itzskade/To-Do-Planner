# To-Do Planner 📝

**To-Do Planner** is a lightweight and efficient productivity application designed to help you organize your daily tasks and to-dos. Developed in Python, it allows you to easily manage your time, track your progress, and keep your daily life perfectly organized in a simple and intuitive way.

---

## 🌟 Key Features

* **Task Management:** Add, list, and complete your daily tasks effortlessly.
* **Lightweight & Fast:** Minimal resource usage for quick and instant planning.
* **Standalone Executable:** Can be compiled into a single binary so it runs natively without requiring Python to be installed.
* **Data Persistence:** Keeps your to-do lists safely stored locally.

---

## 🛠️ Commands & Usage

This project includes a streamlined automation workflow. You can manage everything using simple terminal commands:

| Command | Description |
| :--- | :--- |
| `make install` | Sets up the virtual environment and installs all required dependencies. |
| `make run` | Runs the To-Do Planner application directly. |
| `make build` | Compiles the application into a standalone executable. |
| `make clean` | Cleans up build artifacts, cache, and temporary files. |
| `make fclean` | Performs a deep clean, including the removal of the virtual environment. |
| `make remove` | Deletes the local application data/database. |

---

## 🚀 Getting Started

1. Clone or download the repository to your local machine.
2. Open your terminal in the project root directory.
3. Run `make install` to prepare the environment.
4. Run `make run` to start planning your day!
